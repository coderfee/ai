| [init](./skills/init/SKILL.md) | 项目初始化规范生成 | 创建新项目、统一AI开发上下文、生成协作准则 |
| [commit](./skills/commit/SKILL.md) | Git 标准化提交流程 | 提交代码、生成规范提交消息、拆分多模块改动 |
| [android-build](./skills/android-build/SKILL.md) | Android 自动构建发布 | 打包APK、自动版本号管理、多渠道构建 |
| [flutter-build](./skills/flutter-build/SKILL.md) | Flutter 项目自动构建 | 打包Flutter应用、多平台构建、真机自动安装 |
