# explore Skill

自动克隆 GitHub 仓库到本地并按照用户需求进行代码研究分析。

## 工作流程

1. **解析输入**：从用户输入中提取 `owner/repo` 和研究需求描述
2. **路径检查**：检查当前目录下是否已存在 `owner/repo` 目录
3. **自动克隆**：如果不存在，使用 `gh repo clone` 克隆仓库到对应路径
4. **进入目录**：克隆完成（或已存在）后，切换工作目录到目标仓库
5. **研究分析**：按照用户需求执行代码探索、架构分析、功能研究等
6. **结果输出**：整理研究结果，结构化呈现给用户

## 输入格式

用户输入必须遵循以下格式：
```
/explore owner/repo 研究需求描述
```

- 第一个参数必须是 GitHub 仓库格式 `owner/repo`
- 后续所有文本作为研究需求
- 如果用户只输入 `/explore owner/repo`，默认进行全面架构分析

## 约束规则

- **权限安全**：仅克隆公开仓库，私有仓库访问依赖 GitHub CLI 的当前认证
- **清理策略**：不自动删除已克隆仓库，由用户手动管理
- **工作目录**：始终相对于当前工作目录创建 `owner/repo` 路径，不支持自定义路径
- **错误处理**：克隆失败时清晰报告错误信息（网络问题、仓库不存在等）
- **静默克隆**：克隆过程只输出关键信息，不输出完整 git 日志

## 默认行为

- 无研究需求时，默认执行：架构概览、入口文件分析、技术栈识别
- 已存在仓库时，直接进入分析，不重新克隆
- 使用 GitHub CLI 进行克隆，确保认证和网络兼容性

**输出过程**：

路径不存在，开始克隆...
克隆完成: anthropics/claude-code
进入目录，开始分析 skill 系统设计...

[...分析结果...]
```

**输入**：`/explore octocat/Hello-World`

```

[...分析结果...]
