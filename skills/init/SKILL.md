# init

执行 AI 助手的初始化流程，用于生成 AGENTS.md 文件，包含项目的架构设计、技术选型、工作流程等关键信息，为后续开发提供指导和参考。

## 工作流程

1. 深入分析项目
2. 明确需求和目标、架构、技术栈、工作流程
3. 生成 AGENTS.md 文件，确保编程工具能够正确解析和使用其中的信息

## AGENTS.md 规范

- **语言**: 必须使用**简体中文**。
- **格式**: 采用 Markdown 格式，结构清晰，层次分明。
- **内容**: 包含项目的架构设计、技术选型、工作流程等关键信息，确保信息完整且易于理解。

## 模板

```markdown
# AGENTS.md

本文件为 AI 编程工具提供本仓库操作指引。

## 使用规则

- 用户偏好语言为简体中文，所有交流和输出请始终使用简体中文。
- 生成代码时禁止添加任何注释。

## 常用命令

- 安装依赖：依赖具体项目的包管理工具，如 `npm install` 或 `uv sync`
- 启动项目：根据项目类型使用相应的命令，如 `npm start` 或 `uv run`
- ...more commands

## 项目架构

根据实际项目情况描述项目的架构设计，包括模块划分、组件关系等。
```
